# Avaliação Formativa — Currículo / Arco (Stage 02)

## Sessão única: Avaliação formativa: o feedback que faz aprender

- **Duração:** 45 min
- **Tarefa âncora (Merrill):** transformar um comentário de nota real em um feedback que o aluno consiga usar para melhorar.
- **Objetivos de aprendizagem (Bloom):**
  1. **Distinguir** avaliação formativa de somativa (entender).
  2. **Analisar** por que nota isolada não é feedback (analisar).
  3. **Produzir** feedback acionável usando as três perguntas (criar).
- **Arco previsto (Merrill):** activation → demonstration → application → integration
- **Ideia-chave:** avaliar para aprender é redirecionar o ensino enquanto ainda há tempo.

### Mapa do arco → chunks

| Fase Merrill | Chunks | Intenção |
|--------------|--------|----------|
| Task-centered / Activation | 1 | provocar: o feedback chega a tempo? |
| Demonstration | 1, 2, 3, 4 | formativa×somativa, nota×feedback, 3 perguntas, ciclo |
| Application | 5 | reescrever um comentário em feedback acionável |
| Integration | 6 + síntese | foco/tempestividade; avaliar para redirecionar o ensino |
