# Cefor Slides

Sistema de produção de slides instrucionais para o Cefor, fundamentado em 4 camadas pedagógicas (`shared/methodology.md`). Configure uma vez (`setup`), produza por curso/aula.

## Roteamento por modo

- **Modo 1 — Produção** (conteúdo pronto): entre no Stage 03 (outline). Aplica Sweller + Mayer + Alley + design Cefor.
- **Modo 2 — Design pedagógico** (conceitos): entre no Stage 02 (currículo). Aplica as 4 camadas (Merrill desenha o arco).

## Roteamento por tarefa

| Tarefa | Vá para | Descrição |
|--------|---------|-----------|
| Extrair conteúdo da fonte | `stages/01-extraction/CONTEXT.md` | Pontos de ensino estruturados de PDFs, textos, notas |
| Desenhar arco instrucional | `stages/02-curriculum/CONTEXT.md` | Organizar em sessões/objetivos com sequência Merrill |
| Outline de slides | `stages/03-outline/CONTEXT.md` | Slides assertion-evidence (Alley + Mayer) |
| Gerar decks | `stages/04-generation/CONTEXT.md` | .pptx no design Cefor via html2pptx |
| QA e entrega | `stages/05-qa-delivery/CONTEXT.md` | Rubrica pedagógica + visual, entrega |
