# Curriculum Format — arco instrucional (Merrill)

Como é um currículo bem-formado no `cefor-slides`. A sequência segue os **First Principles of Instruction (Merrill)** e os objetivos usam **Bloom revisada**. Ver `shared/methodology.md`.

## Arco de cada sessão (Merrill)

Toda sessão organiza seus slides nesta progressão (substitui o "story arc" persuasivo):

1. **Task-centered** — abrir com a tarefa/problema real que dá sentido.
2. **Activation** — ativar conhecimento prévio do aluno.
3. **Demonstration** — demonstrar o conceito (mostrar, com evidência visual).
4. **Application** — o aluno aplica (atividade/caso).
5. **Integration** — integrar ao contexto de atuação do aluno.

## Estrutura

```markdown
# [Nome do Curso] -- Currículo

## Módulo 1: [Título]

### Sessão 1.1: [Título]
- **Duração:** [X] min
- **Tarefa âncora (Merrill):** [problema/tarefa real da sessão]
- **Objetivos de aprendizagem (Bloom):**
  1. [verbo de ação + resultado observável]
  2. [verbo de ação + resultado observável]
- **Arco previsto:** activation → demonstration → application → integration
- **Conteúdo:** [chunks alocados]
- **Ideia-chave:** [uma frase que o aluno deve reter]
```

## Regras

1. Cada sessão cobre 3–7 chunks (não mais).
2. Mínimo 2 objetivos por sessão.
3. Objetivos começam com verbo de ação (Bloom): lembrar, entender, aplicar, analisar, avaliar, criar.
4. Sessões de um módulo constroem umas sobre as outras — a ordem importa (foundations antes de applications).
5. Toda sessão tem uma **tarefa âncora** (Merrill task-centered), não só uma lista de tópicos.
6. Sinalizar sessões que pedem gráfico/dado/imagem — informa o Stage 03.

## Dimensionamento

| Slides | Densidade | Indicado para |
|--------|-----------|---------------|
| 10–15 | leve — visão geral | aberturas, sessões curtas |
| 15–25 | padrão — maioria | conteúdo central |
| 25–35 | denso — aprofundamento | sessões técnicas/dados |

Mire a faixa padrão, salvo necessidade clara. Lembre Sweller: mais slides com 1 ideia cada > slides densos (segmentação).
